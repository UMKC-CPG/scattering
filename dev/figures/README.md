# Figures

Diagrams used by the chain documents, together with the editable
source that produced each one. Keep the pair adjacent and identically
named: `pipeline-v2.png` next to `pipeline-v2.pptx` or
`pipeline-v2.svg`. A raster figure whose source has been lost cannot
be corrected, only redrawn.

Version figures by name rather than by overwriting. A chain document
that cites a figure is citing what it showed at the time, and an
in-place edit silently rewrites that citation.

Note that `.gitignore` excludes `*.png` project-wide (rendered output
is regenerable) but makes an exception for this directory.
